Login, hak akses, dan pola proses transaksi

A. Login & hak akses

1Loginusers (username, password, status aktif, cabang); lupa password lewat reset_tokens
2Role useruserrole → role
3Hak aksesacl (per role) + useracl (per user) → acos class/method
4Menu dinamismenus ditampilkan bila aco_id-nya diizinkan
5Buka formgrid membaca view v… (mis. vpengeluaranheader)

B. Pola setiap form transaksi

1Tambah / Editrecord dikunci di locks (editing_by, editing_at); dibuka lewat menu Buka Lock Edit
2Nomor buktiformat dari parameter / bank.format…, reset per bulan atau tahun
3Simpantabel …header + …detail; status dari parameter
4Auditlogtrail menyimpan data JSON, aksi, tabel, nomor bukti
5Approval & cetakstatuspendukung (APPROVAL TRANSAKSI, CETAK)
6Postingke kas/bank, hutang, dan jurnalumumheader/detail (kolom postingdari)
7Laporanmenu Laporan / General Ledger

Pola B berlaku untuk transaksi ber-header/detail: orderan, SI, BL, biaya, tarif biaya EMKL, penerimaan, pengeluaran, kas gantung, hutang, jurnal. Tabel listtemporarytable dan tabel temp_… dipakai sebagai tabel kerja grid per user.

Temuan & rekomendasi

DataData uji/dummy bercampur dengan data riil

pengeluaranheader (1.010.083 baris) berisi 900.000 baris (kosong) (oleh SUNTIKDATA), 100.005 baris PENGELUARAN SEED (oleh seed), 9.994 baris AUTO INSERT DUMMY (oleh sa); pengeluarandetail 2.150.109 baris; alatbayar 1.010.624 baris (master yang seharusnya kecil); typeakuntansi 5.045 baris; master uji seperti jenis order TEST/TESTF/UJIAN/WWW, cabang PISANG/TES2/TEST/TESTDFG, role TEST/UJIAN.

StrukturFK terdefinisi ganda

Ada 681 constraint FK untuk 391 pasangan kolom→tabel unik; banyak FK dibuat lebih dari sekali sehingga memperlambat insert/update.

StrukturBeberapa relasi tanpa FK

penerimaandetail.penerimaan_id, shippinginstructiondetailrincian → detail, kolom alatbayar_id di transaksi kas/bank, marketingmanager.managermarketing_id, dan rujukan transaksibiaya_nobukti tidak dijaga database.

StrukturTipe data kurang tepat

Hampir semua kolom bertipe text (termasuk id); beberapa tanggal/angka disimpan sebagai text (hutangdetail.tglinvoiceemkl, packinglistdetailrincian.banyak/berat, shipper_user_1.created_at).

KebersihanTabel sementara & duplikat tertinggal

7 tabel sementara/backup, shipper_user_1 (218.336 baris) di samping shipper (1 baris), dan sysdiagrams sisa SQL Server.

KeamananKoneksi & kolom sensitif

Server .56 belum mengaktifkan SSL (koneksi saat ini tanpa enkripsi). Kolom shipper.passwordtracing bertipe text — pastikan tidak menyimpan password polos.
